# Stark Industries Endpoint Engineering Lab — Project Tracker

## Project Goal

Build a small, portfolio-focused home lab demonstrating the core skills needed for Endpoint Engineer, Desktop Engineer, and EUC roles.

**Target project time: 12–15 hours**

## Scope Rule

Only add work that materially improves:

- Endpoint engineering skills
- Interview readiness
- Resume/portfolio value

Avoid unnecessary infrastructure, duplicate work from previous labs, and excessive documentation.
